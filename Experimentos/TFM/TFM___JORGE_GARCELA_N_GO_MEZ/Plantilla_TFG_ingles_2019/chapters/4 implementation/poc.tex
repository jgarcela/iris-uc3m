To ensure robust evaluation of our experiments, we split the dataset into the same training and test sets for the machine and deep learning models, as detailed in Figures~\ref{fig:ml_models_implementation} and~\ref{fig:dl_models_implementation} respectively. Notice that for generative models we have not applied any data splitting as we are following the zero-shot learning approach, as commented in Section~\ref{zero_shot}.

For the ML experiments, this was done using the \textit{"Sklearn"} python library and the \texttt{train\_test\_split} function with the \texttt{random\_state=0} parameter and \texttt{stratify} to maintain the original class distribution in both sets. The stratified splitting ensures that both the training and test sets have a similar distribution of classes as the original dataset. Specifically, we allocated 80\% of the data for training and 20\% for testing. 

For the DL experiments, we followed a similar approach also utilizing a stratified splitting technique and with the \texttt{random\_state=0} parameter. In this case, the process involved an initial split of 80\% of the data for training and validation and 20\% for testing. Subsequently, the training and validation set was further divided, allocating 90\% of the remaining data to training and 10\% to validation.
