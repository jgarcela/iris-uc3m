This section is dedicated to present the set of python libraries that have been used for the development of this thesis:

\begin{itemize}
    \item \textbf{Pandas:} A data manipulation and analysis library that provides data structures and operations for manipulating numerical tables and time series.
    \item \textbf{Numpy:} A library that adds support for large, multi-dimensional arrays and matrices, along with a large collection of high-level mathematical functions to operate on these arrays.
    \item \textbf{Uuid:} Provides immutable UUID objects (Universally Unique IDentifiers) and functions for generating UUIDs.
    \item \textbf{Joblib:} A set of tools to provide lightweight pipe-lining in Python by using serialization to optimize for large numpy arrays.
    \item \textbf{Time:} Provides various time-related functions for Python.
    \item \textbf{Sklearn (Scikit-learn):} A simple and efficient tools for predictive data analysis built on NumPy, SciPy, and matplotlib.
    \item \textbf{Torch (PyTorch):} An open-source machine learning library, based on Torch, used for applications such as natural language processing.
    \item \textbf{Re:} Provides regular expression matching operations similar to those found in Perl.
    \item \textbf{String:} Contains a number of functions to process standard Python strings.
    \item \textbf{Nltk (Natural Language Toolkit):} A suite of libraries and programs for symbolic and statistical natural language processing.
    \item \textbf{Emoji:} Provides tools for handling emojis in Python strings.
    \item \textbf{Transformers:} State-of-the-art machine learning models for natural language processing tasks, built on top of PyTorch and TensorFlow.
    \item \textbf{Gensim:} A robust semantic modeling library, useful for topic modeling and document similarity analysis.
    \item \textbf{Imblearn (Imbalanced-learn):} Provides tools for dealing with class imbalance in machine learning.
    \item \textbf{Xgboost:} An implementation of gradient boosted decision trees designed for speed and performance.
    \item \textbf{Itertools:} Provides a collection of tools for handling iterators. It offers complex functions and helper tools for working with iterable data sets.
    \item \textbf{Matplotlib:} A plotting library which produces publication quality figures in a variety of hardcopy formats and interactive environments.
    \item \textbf{Datasets:} Provides easy access to a wide range of datasets and preprocessing functions, particularly useful for benchmarking machine learning models.
    \item \textbf{Collections:} Implements specialized container datatypes providing alternatives to Python’s general purpose built-in containers, dict, list, set, and tuple.
    \item \textbf{Pathlib:} Offers a set of classes to handle filesystem paths with semantics appropriate for different operating systems.
    \item \textbf{Tqdm:} A fast, extensible progress bar for loops and or code blocks, providing visual feedback.
    \item \textbf{Requests:} Allows sending HTTP/1.1 requests, adding the ability to connect to a given URL and retrieve information from it.
    \item \textbf{Json:} Implements the JSON format parsing and generation. Provides methods to encode and decode JSON data.
    \item \textbf{Seaborn:} A data visualization library based on matplotlib providing a high-level interface for drawing attractive and informative statistical graphics.
    \item \textbf{Wordcloud:} A tool for creating image word clouds, a visual representation of text data where the size of each word indicates its frequency or importance.
    \item \textbf{Plotly:} An interactive graphing library for Python (and other programming languages), capable of producing high-quality graphs and figures.
\end{itemize}
