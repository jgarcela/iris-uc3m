%----------	

 Another critical aspect of text data cleaning involves the handling of stopwords. \cite{manning-2008} defines stop-words as \textit{"extremely common words which would appear to be of little value in helping select documents matching a user need"}.
A detailed overview has been made in the corpus of Spanish stop-words provided by the \textit{nltk} python library. It is remarkable that the word \textit{"no"} belongs to the set. It is not a good strategy to remove this word from our texts as it provides negative context, so for the scope of this work, the decision was to not remove it.
