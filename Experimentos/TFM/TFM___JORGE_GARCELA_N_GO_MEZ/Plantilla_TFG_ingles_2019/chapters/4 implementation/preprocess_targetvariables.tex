In Tables~\ref{tab:ageneral-support},~\ref{tab:cnegativo-support},~\ref{tab:insultos-support} we can see the support for each label in each of the three target variables that we are considering. Notice that it has been considered to remove low-represented classes in each category, in order to facilitate the classification. In particular, for AG we have discarded "Comentario Neutro", in CNEG "Sexualización/Objetivización", "Estereotipos de Género" and "Violencia de Género", and for INS we have added "Sarcasmo", "Imposición" and "Objetivización Sexual" to "Genéricos".
