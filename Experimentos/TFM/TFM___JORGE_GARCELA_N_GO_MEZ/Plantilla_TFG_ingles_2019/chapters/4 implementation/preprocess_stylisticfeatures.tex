\cite{fersini-2018} proposes a series of stylistic features in order to add linguistic information about the tweet to the classification process. Following that approach, new variables have been created:
\begin{itemize}
    \item \textbf{Count of User Mentions:} Adding this information could be potentially useful when detecting hate speech as we are able to capture if it is directed to a person or a collective.
    \item \textbf{Length of Tweet:} This data could help identify HS as there could be a relation in the number of words in a tweet with the use of insults.
    \item \textbf{Number of Adjectives:} Tweets that contain HS tend to have a higher number of adjectives, making it useful when trying to detect hate speech.
\end{itemize}
