Effective data pre-processing is a fundamental step in any Natural Language Processing (NLP) project. Text data can be complex and unstructured, presenting various challenges for analysis and training, so in order to address these challenges and ensure that our models perform optimally, it is essential to clean and prepare the data meticulously. We have followed some techniques discussed and implemented in different works, such as \cite{fersini-2018}, \cite{degregorio-2024}, \cite{blanco-2024} and \cite{perez-2024}. In Figure~\ref{fig:preprocessing} we can see a diagram of the different steps performed.
