The first model that was implemented in our project was Random Forest. It was first introduced in \cite{KamHo-1995}, where they used the random subspace method, also called attribute or feature bagging, to create an ensemble-like classifier using decision trees (CART). A further and more proper implementation was presented in \cite{breiman-2001}. At its core, a Random Forest model consists of many individual decision trees, each constructed to reach a conclusion (leaf node) based on different subsets of features and data points. By doing so, it improves the performance and accuracy of a single decision tree by combining the outputs of multiple decision trees.
