Before the rise of Generative AI, developing NLP applications required creating a complex procedure, involving a thorough preprocessing of data as described in Section~\ref{sec:data_preprocessing}, and the implementation of complex techniques. However, generative models, which are trained in vast amounts of data containing diverse sources, web documents, code, and mathematical text, simplify this process for the user by integrating these steps into short and simple tasks. One example of this is the zero-shot learning approach detailed in Section~\ref{zero_shot}, which allows models to handle a wide range of tasks without explicit training, drastically reducing time and the need for extensive preprocessing. 

These models can be accessed via two main approaches: web interfaces like ChatGPT\footnote{From \url{https://chatgpt.com/}, last visited 03/08/24} and Gemini\footnote{From \url{https://gemini.google.com/app}, last visited 03/08/24}, which allow usage even without subscription, though data privacy remains a concern. Alternatively, open-source LLMs can be downloaded and run on local computers, but they require high-performance hardware due to their size.
