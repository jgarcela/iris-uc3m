The source code developed for this thesis has been organized into four main directories as detailed in Figure~\ref{fig:appendix_sourcecode}, each corresponding to the different approaches. The repository has been published on GitHub and can be accessed through the following link: \url{https://github.com/jorgegarcelan/HS-Detection-SeAcabo}.

\begin{itemize}
    \item \textbf{MachineLearning:}
    \begin{itemize}
        \item \texttt{ML Experiments}: Folder that contains the Excel files of the ML experiments.
        \item \texttt{EDA.ipynb}: A Jupyter notebook for performing Exploratory Data Analysis (EDA) on the dataset, helping to understand the data before model development.
        \item \texttt{Plots.ipynb}: A notebook dedicated to visualizing various metrics and results obtained from the Machine Learning models.
        \item \texttt{visualize\_embeddings.ipynb}: A notebook for visualizing the embeddings generated from the dataset, helping to understand the feature space.
        \item \texttt{load\_data.py}: A script for loading the dataset into the environment, preparing it for further processing.
        \item \texttt{process\_data.py}: Handles the preprocessing of data before it is used in model training.
        \item \texttt{create\_embeddings.py}: A script to generate embeddings from the dataset, which are used as features for the models.
        \item \texttt{split\_data.py}: A script to split the dataset into training and testing sets, a crucial step in model development.
        \item \texttt{create\_model.py}: A script responsible for creating and configuring the Machine Learning models.
        \item \texttt{evaluate\_model.py}: This script evaluates the performance of the trained Machine Learning models, providing metrics and insights.
        \item \texttt{run\_to\_excel.py}: This script exports the results of the models into an Excel file for additional analysis.
        \item \texttt{train\_ML.py}: Principal Python script that integrates all functions and used to train the Machine Learning models.
        \item \texttt{utils.py}: Contains utility functions that support various tasks across the Machine Learning workflow.
    \end{itemize}
    \newpage

    \item \textbf{DeepLearning:}
    \begin{itemize}
        \item \texttt{DL Experiments}: Folder that contains the Excel files of the DL experiments.
        \item \texttt{train\_DL.ipynb}: Notebook to train Deep Learning models.
        \item \texttt{Plots.ipynb}: Notebook for visualizing the results and performance metrics.
    \end{itemize}

    \item \textbf{GenerativeAI:}
    \begin{itemize}
        \item \texttt{GenAI Experiments}: Folder that contains the Excel files of the GenAI experiments.
        \item \texttt{Plots.ipynb}: A Jupyter notebook for visualizing the results and performance metrics of the Generative AI models.
        \item \texttt{embeddings.ipynb}: A notebook dedicated to generating and processing embeddings using the OpenAI API.
        \item \texttt{process\_data.py}: A script for preprocessing the data before feeding it into the models.
        \item \texttt{model.py}: This script is responsible for defining and configuring the models.
        \item \texttt{eval\_model.py}: A Python script for evaluating the performance of the trained models.
        \item \texttt{run\_to\_excel.py}: This script is used to export the results of the models to an Excel file for further analysis.
        \item \texttt{train\_GenAI.py}: Principal Python script for training the models.
    \end{itemize}
\end{itemize}
