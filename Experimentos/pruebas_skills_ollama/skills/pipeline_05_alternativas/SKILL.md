# Skill 5 — Propuesta de alternativas

Para hallazgos donde tenga sentido una reformulación:

1. Propón **`texto_propuesto`** en **registro periodístico profesional**, inclusivo y preciso.
2. Mantén el **`texto_original`** igual al `excerpt` (o subcadena clara) del hallazgo.
3. Enlaza con **`finding_id`** del hallazgo correspondiente.

Rellena el array **`alternatives`** del JSON unificado. Si no hay alternativa razonable, puedes omitir entradas o dejar `texto_propuesto` vacío con `notas` explicando el motivo.

El campo opcional **`annotated_summary`** puede ser un párrafo breve de síntesis; no sustituye offsets ni `findings`.
